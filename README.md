# ai-joke-03 — The Wrong Feature

A make.fun entry for "Make the AI judge laugh" (ai-joke-03, $150 in USDC).

The entry is a small Python program that writes one fixed one-liner about
AI coding agents to `/output/entry.txt`. The joke is constant text, so the
program is deterministic: every run writes the same bytes. It uses no
network, no randomness and no clock.

## Run it

```sh
python3 main.py
```
